# ドメイン用語集

> コード上の命名とドキュメント上の用語をそろえるための対応表。
> 番号の範囲・カードの大きさは一般的なビンゴの例。採用するかは仕様整理（論点 Q6）で決める。

## 基本用語

| 用語 | 英語表記 | 定義 |
|------|---------|------|
| 主催者 | host | 番号を抽選し、ゲームを進行する人 |
| 参加者 | player | カードを持って遊ぶ人 |
| ゲーム | game | 1回のビンゴ（抽選開始〜終了） |
| 抽選 | draw | まだ出ていない番号から1つをランダムに選ぶこと |
| 抽選機 | ball machine | 球を混ぜて1つ出す装置。画面上でこの映像を見せる |
| ガラガラ | lottery drum | 八角形の箱をハンドルで回し、球を1つ出す福引の抽選器。本アプリの抽選機はこれ（Q7-1） |
| 球 | ball | 抽選機から出てくる、番号が書かれた玉 |
| 番号 | number | 抽選の対象になる数字（一般的には 1〜75） |
| 出た番号 | drawn numbers | そのゲームで抽選済みの番号の一覧 |
| カード | card | 参加者ごとのマス目（一般的には 5×5） |
| マス | cell | カードの1枠 |
| フリー | free cell | 最初から開いているマス（一般的には中央） |
| マーク | mark | 出た番号のマスを開けること |
| リーチ | reach | あと1マスで1列がそろう状態 |
| ビンゴ | bingo | 縦・横・斜めのいずれか1列がそろった状態 |

## 一般的なカードの列と番号

| 列 | B | I | N | G | O |
|----|---|---|---|---|---|
| 番号 | 1〜15 | 16〜30 | 31〜45 | 46〜60 | 61〜75 |

## ロール

| ロール（概念） | 権限概要 |
|---------------|---------|
| 主催者 | ゲームの開始・抽選・終了（詳細は仕様整理で決める） |
| 参加者 | 自分のカードの表示・マーク（詳細は仕様整理で決める） |
