# ビンゴ Web アプリ

対面の集まりで、主催者の PC をモニターに映して使うビンゴの抽選画面です。
ガラガラ（福引の抽選器）から球が出てくる演出で番号を抽選し、今までに出た番号も確かめられます。

> **開発中**です。いまあるのは、見せ方を比べるための試作だけです。

## 試作

[prototype/display-compare.html](prototype/display-compare.html)

- ファイルをブラウザで開くだけで動きます（サーバ不要）
- 出た番号と設定はブラウザに保存され、リロードしても続きから再開できます

| 操作 | 内容 |
|---|---|
| Space / Enter | 抽選 |
| H | 出た番号の表示切替（切り替えモードのとき） |
| F | 全画面 |
| P | 試作バーの表示切替 |
